Your supplier sends an invoice with an HS code on it. Your customs agent asks for the TARIC code. They are not the same number, and the difference decides which duties and rules apply to your goods.

This is how we would find the right TARIC code, in five steps. It covers the digit structure, what the TARIC database actually contains and where an exporter from India most often goes wrong.

**At a glance:**

- The **HS code has 6 digits**, the EU's **Combined Nomenclature (CN) has 8** and the **TARIC code has 10**.
- TARIC is the EU's **integrated tariff**: duties, preferences, quotas, anti-dumping duties, prohibitions and controls in one database.
- Some measures also need a **4-character additional code**.
- Germany asks for an **11-digit code** on import declarations. Eight digits are enough for export.
- A **binding tariff information (BTI)** removes doubt for three years.

## 1. Start with the 6-digit HS code

Every classification starts with the Harmonised System. The first six digits are the same in the EU, India and most other countries, so your supplier's HS code is a fair starting point. It is not the end. The EU adds more digits, and those extra digits are where the EU's own rules sit. If you need a refresher, [how to read an HS code](/blog/what-is-an-hs-code) walks through the structure.

## 2. Extend to 8 digits and then 10

The EU's Combined Nomenclature takes the six HS digits and adds two. TARIC adds two more. So the code runs from 6 to 8 to 10 digits, according to the Luxembourg government's guidance on the [NC and TARIC codes](https://guichet.public.lu/en/entreprises/import-export/codes/tarifs-codes-indispensables/nc-taric.html). The TARIC code is generally what an import declaration uses. For export, the 8-digit CN code is the usual one.

Do not copy digits 7 to 10 from the supplier's invoice. A supplier outside the EU has no reason to know them. They carry EU measures such as anti-dumping duties and suspensions. Germany goes one step further and uses an 11-digit code for import declarations, as we explain in [Zolltarifnummer finden](/de/blog/zolltarifnummer-finden) (in German).

## 3. Look the code up in the TARIC database

The [European Commission describes TARIC](https://taxation-customs.ec.europa.eu/online-services/online-services-and-databases-customs/eu-customs-tariff-taric_en) as a multilingual database that brings together all measures of the Common Customs Tariff and trade and agricultural legislation, so they apply the same way in every EU country. It is updated and sent to national administrations daily.

For each code it lists measures such as:

- the third-country duty and tariff preferences
- autonomous suspensions and tariff quotas
- anti-dumping, countervailing and safeguard duties
- prohibitions and restrictions, and quantitative limits
- controls, for example CITES, dual-use, veterinary and phytosanitary
- surveillance

Access is free. The Commission also publishes the raw data in Excel. TARIC does not contain national charges such as VAT and excise, so those you check separately.

## 4. Check the measures for your origin, and the additional codes

A code on its own does not tell you the duty. Measures are listed against countries, so look up your goods for the country they come from, not only the code. An exporter in India should read the lines for India, and for any trade agreement that could apply, before quoting a landed price.

Some measures also ask for a 4-character TARIC additional code on the declaration. The Commission's database holds those additional codes, and the Luxembourg guidance gives V999 as an example. If the lookup shows an additional code for your goods, make sure it reaches your agent.

## 5. Get a binding answer if the stakes are high

If two codes look possible and the duty difference is large, ask customs for a binding decision instead of guessing. In Germany that is the verbindliche Zolltarifauskunft. A binding tariff information is binding on the customs authorities of all member states and is valid for three years under the [Union Customs Code](https://eur-lex.europa.eu/eli/reg/2013/952/oj). Apply before the goods move.

## Common mistakes

- Using the supplier's HS code unchanged, so digits 7 to 10 are missing.
- Looking up the code but not the country of origin.
- Using last year's code. The EU adjusts the Combined Nomenclature every year, so check the current version.
- Missing the additional code that a measure asks for.

## FAQ

**What is a TARIC code?**
It is the 10-digit code used in the EU's integrated tariff, built from the 6-digit HS code, the 8-digit CN code and two further digits. It links goods to the duties and rules that apply to them.

Source: [Luxembourg government: NC and TARIC codes](https://guichet.public.lu/en/entreprises/import-export/codes/tarifs-codes-indispensables/nc-taric.html)

**What is the difference between an HS code and a TARIC code?**
The HS code has 6 digits and is common to most countries. The TARIC code has 10 digits and adds EU-specific detail, including measures such as anti-dumping duties.

Source: [European Commission: TARIC](https://taxation-customs.ec.europa.eu/online-services/online-services-and-databases-customs/eu-customs-tariff-taric_en)

**Is the TARIC database free to use?**
Yes. The Commission offers it free of charge online, and the raw data is available as Excel files.

Source: [European Commission: TARIC](https://taxation-customs.ec.europa.eu/online-services/online-services-and-databases-customs/eu-customs-tariff-taric_en)

**Does TARIC include VAT?**
No. It does not contain national levies such as VAT and excise duties.

Source: [European Commission: TARIC](https://taxation-customs.ec.europa.eu/online-services/online-services-and-databases-customs/eu-customs-tariff-taric_en)

**How long is a binding tariff information valid?**
Three years. It binds the customs authorities of all member states.

Source: [EUR-Lex: Regulation (EU) No 952/2013](https://eur-lex.europa.eu/eli/reg/2013/952/oj)
